## 一、它能做什么

对 **A 股上市公司的年度报告**（文字版 PDF、非金融业），自动抽取三张报表的
18 个关键科目，并且**给每个数值标注置信度**：

| 档位 | 含义 | 你该怎么做 |
|---|---|---|
| **高置信** | 与独立数据源核对一致（上市公司）；或内部证据一致（私密材料） | 可以直接用 |
| **低置信** | 合并/母公司口径证据打架，或与对照源不一致 | **必须人工核对**，页面上给了候选值和页码 |
| **拒答** | 没抽到，或这份材料不适用自动解析 | 不要用它给的任何数，人工处理 |

**实测成绩**（33 份材料、20 家公司，含创业板/科创板/沪深主板/北交所）：

```
上市公司   高置信字段覆盖率 91%，正确率 100%
私密材料   高置信字段覆盖率 40%，正确率 99.1%
```

**私密材料覆盖率只有 40%** —— 意思是：没有外部数据可核对时，
它只对 40% 的字段敢下结论，其余 60% 会明确标成"低置信/拒答"交给你。
**这是设计如此，不是坏了。**

## 二、别拿这些来测（会文件级拒答）

```
✗ 扫描件 / 图片型 PDF（OCR 路径未达标）
✗ 金融业：银行、保险、券商（科目体系完全不同）
✗ 美股 10-K（HTML 载入未做）
✗ 港股（金融业科目组未做、样本不足）
✗ 英文版年报（通常整表定位不到）
✗ T 型双栏排版的报表、加密 PDF
```

**这些会明确告诉你"这份材料目前解析不出来"，不会给你编一个数。**

## 三、安装与首次运行（已实测）

```bash
git clone https://github.com/NCV-Developer/freeanalyst.git
cd freeanalyst
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt     # 只有 pdfplumber 一个依赖
.venv/bin/python freeanalyst.py doctor        # 环境自检
```

把一份或多份年报 PDF 放进一个目录，然后：

```bash
.venv/bin/python freeanalyst.py appraise /path/to/目录 --out /tmp/out
```

**注意：`appraise` 收的是目录，不是单个 PDF。**

它会打印每张表映射了多少行、单位、合并口径，并生成一份问答清单
`/tmp/out/估值问答.txt`。把里面要的假设填上（**空着的它不会替你猜**），再跑一次：

```bash
.venv/bin/python freeanalyst.py appraise /path/to/目录 --out /tmp/out \
    --answers /tmp/out/估值问答.txt
```

**取数和对账不需要下载任何模型**；抓可比公司才需要联网。

**已知环境坑**：如果报 `PdfDependencyMissing`，先确认你用的是不是 3.12。

## 四、内测最想收集的反馈（不是"能不能解析更多"）

```
1. 拒答理由看得懂吗？   看到「这份材料目前解析不出来」，你知道接下来怎么办吗？
2. 低置信提示有用吗？   给了候选值和页码，你能不能快速人工核对？
3. 安装顺不顺？         卡在哪一步？
4. 有没有"高置信但其实是错的"？ **这条最重要** ——
   这版的设计目标就是"敢给结论的必须对"，发现一例请立刻告诉我。
```

## 五、已知个案（不用重复报）

```
· 某大型地产公司经营活动净额符号异常（与对照源方向相反），内部证据没拦住 —— 已知，列入待修
· 某家电公司：三表定位不到 → 文件级拒答
· 数家发行人（石化、券商、保险）：覆盖不足 → 文件级拒答
```

---

**一句话：这版的价值不是"什么都能解析"，而是"它说能的，你可以信；它说不能的，会告诉你"。**
